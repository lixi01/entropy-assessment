# 熵减践行工具包 - 多维熵值评估量表

一个基于熵减理论的个人成长评估工具，帮助你了解自己的思维模式和能量状态。

## 功能特点

- 📋 32道专业测评题目
- 📊 总熵值评估（低熵/中熵/高熵）
- 🎯 两大主维度分析：封闭程度 & 做功阻力
- ⭐ 五向熵维雷达图可视化
- 🐬 四种成长熵型判定：海豚型、树懒型、犀牛型、海鞘型

## 在线体验

访问：https://lixi01.github.io/entropy-assessment/

## 技术栈

纯前端实现，无需后端服务
- HTML5 + CSS3 + JavaScript
- Canvas 雷达图绘制
- 响应式设计，支持移动端
